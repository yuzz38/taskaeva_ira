# Ира Таскаева — ведущая мероприятий в Анапе | лендинг

Одностраничный сайт для ведущей и турагента Иры Таскаевой (Instagram [@taskaeva_ira](https://www.instagram.com/taskaeva_ira), [ВКонтакте](https://vk.ru/taskaeva_ira)). SEO и GEO настроены на Анапу и Новороссийск.

## Структура страницы (10 блоков)
1. **Первый экран-сцена** — занавес, луч софита следует за курсором (на телефоне двигается сам), фото в арке, билет «для живых эмоций»
2. **Праздники** — форматы в виде билетов с отрывным корешком
3. **Ведущая + диджей** — «микшерный пульт» с фейдерами, видео, где Ира поёт, в рамке телефона
4. **Манифест** — «настоящее, а не глянец»: слова загораются по мере прокрутки
5. **История** — девочка в бантах и софиты, маршрут Иркутск → Анапа, полароиды
6. **Как готовим праздник** — шаги в виде сет-листа диджея с эквалайзером
7. **Галерея** — бенто-сетка с видео праздников и фото
8. **Отзывы** — слайдер (свайп, стрелки, точки, клавиатура), тексты дословно взяты из видео-отзывов
9. **Путешествия** — турагент в Анапе: посадочный талон на фоне видео моря
10. **FAQ + контакты** — аккордеон и кнопки Instagram и VK, футер

## Файлы
```
index.html            — страница: meta, Open Graph, гео-теги, JSON-LD
css/style.css         — стили
js/main.js            — меню, слайдер, анимации, ленивые видео
assets/img/           — фото в WebP + JPG (480 и 960 px)
assets/video/         — короткие беззвучные ролики H.264 + постеры
robots.txt, sitemap.xml, llms.txt, site.webmanifest, favicon.svg
SEO-GEO.md            — семантическое ядро и чек-лист после публикации
```

## Технически
- Адаптив от 320 px, бургер-меню на экранах до 900 px
- iOS Safari и Android Chrome: `playsinline` у видео, `100svh`, safe-area, `-webkit-` префиксы; также Firefox и Edge
- Картинки через `<picture>` (WebP с JPG-фолбэком), `loading="lazy"`, фиксированные размеры против сдвигов макета
- Видео грузятся и играют только в зоне видимости, вне экрана ставятся на паузу
- Поддержка `prefers-reduced-motion`, доступная навигация с клавиатуры, aria-атрибуты
- Без бегущих строк и без сторонних JS-библиотек

## Перед публикацией
- Заменить `https://taskaeva-ira.ru/` на реальный домен (index.html, robots.txt, sitemap.xml, llms.txt)
- Залить папку целиком на хостинг: страница статическая, сборка не нужна
